# Playhaus Content

## Use when
Creating or reviewing organic social content, grids, carousels, reels, captions or recurring formats.

## Workflow
1. Read `/context/brand-context.md` and `/context/creative-system.md`.
2. Identify the content territory: Experience, People, Play or Culture.
3. Start with a recognizable social behavior, tension or occasion.
4. Choose the format because it serves the idea, not because it is trending.
5. Write the hook and visual premise together.
6. Check that the execution communicates the night, not only board-game mechanics.
7. Apply visual non-negotiables from `AGENT.md`.
8. Review for generic cafe language, forced slang and excessive sarcasm.

## Output
For concepts provide: insight, idea, format, visual direction, copy/hook, production notes and CTA only when needed.
