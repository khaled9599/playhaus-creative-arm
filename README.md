# The Playhaus Creative Arm

Persistent creative and marketing operating system for The Playhaus, a board game cafe in Maadi Degla, Cairo.

## Start here on a new account
1. Read `AGENT.md`.
2. Read `context/brand-context.md` and `context/creative-system.md`.
3. Read `HANDOFF.md` for current project state.
4. Use the relevant specialist file under `agents/`.
5. Use `references/source-map.md` for original sources and external skill packs.

## Core principle
Strategy comes before aesthetics. Insight comes before ideas. Board games are the mechanism. Better time together is the value.

## Structure
- `context/`: canonical brand and project knowledge
- `agents/`: specialist operating roles
- `skills/`: Playhaus-specific reusable workflows
- `campaigns/`: campaign knowledge and creative direction
- `references/`: source inventory and external resources
- `assets/`: asset rules and inventory

This repository is designed to make the project portable between ChatGPT and Codex accounts without relying on prior conversation history.
