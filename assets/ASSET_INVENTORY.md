# Asset Inventory and Rules

## Known asset groups from prior work
- Original Playhaus identity presentation, previously supplied as `Archive.zip` with 26 presentation images.
- Current/social Instagram screenshots used to diagnose the digital-expression gap.
- Colored Playhaus logo asset.
- Brand font references and lockup references.
- Hand-drawn scribble system: coins, cards/hands, crowns, trophies, winner lettering, reaction faces, meeples, boards and related game motifs.
- Board-game reference packs for Catan, Dixit and Coup.
- Generated people-playing imagery and social-post explorations.
- Carousel reference images supplied for structural inspiration.

## Rules
- Board-game packs are visual/game references, not final creative assets.
- Never use white as a background or text-background panel.
- White can be used for text and scribbles.
- Never desaturate the scribbles.
- Do not place text over faces.
- Use the colored logo without adding a black frame behind it.

## Binary files
This repository currently contains the operating knowledge and asset inventory. Original binary assets should be uploaded separately when available because the current GitHub connector writes UTF-8 text files only. Do not substitute guessed assets for originals.
